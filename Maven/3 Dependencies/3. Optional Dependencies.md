- Sometimes, you have features that you use while developing but the user don't need them all.
  Example, While developing you have JDBC for all databases oracle, mysql, postgresql. 
  Why should we make it mandatory for user to download all drivers for all databases to use our library?
  thats why we use Optional dependencies
- If user want to use specific dependency, he need to explicitly to declare it.
- Now when someone use our library, he won't download all transitive dependencies.

```
mylibrary
├── feature1, Mysql
├── feature2, oracle
├── feature2, postgresql  --> user use only one of those
```

```xml
<dependencies>
  <dependency>
    <groupId></groupId>
    <artifactId></artifactId>
    <optional>true</optional>
  </dependency>
</dependencies>
```
