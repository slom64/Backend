# Mediation
- If we have dependency that is used in different verions in other dependenies. Then which version is used?
	- maven use BFS, so if we firstly found dependecy that use use `A 3.2.0` and then we found another dependency that use `A 1.1.1` it will use `A 3.2.0`


> [!Attention]
> Order of declaring dependencies matters.

# Exclusion
- If we want to exclude some dependencies from specific dependency.
- Example, `junit` use `hamcrest` dependency.
```xml
  <exclusions> <!-- exclude specific dependency from this dependency -->
	  <exclusion>  
	  <groupId>org.hamcrest</groupId>
	  <artifcatId>hamcrest</artifcatId>
	  </exclusion>
  </exclusions> 
```
