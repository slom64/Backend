# Properties
- We use properties as variables so you don't repeat yourself.
- In POM there is user-defined and pre-defined variables.
- You can define the preperty inside `<properties>`, and you can reuse them using `${property_name}`

```xml
<properties>
	<project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
</properties>
```


---
### Pre-defined
- Those properties are available by default in all maven projects


| Property                                                          | Description                                                                                                     |
| ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `${project.}`<br>`${project.artifactId}`<br>`${projecct.groupId}` | Enable us to access all properties in `pom.xml`<br>you can use `${pom.}`. its deprecated, but still you can use |
| `${settings.}`                                                    | Access properties in `settings.xml`                                                                             |
| `${env.}`<br>`${env.PATH}`                                        | Access env variables.                                                                                           |
