- Make sure to have `@AllArgsConstructor` before the controller so spring can use bean the controller and its fields. Example, if you use repository, then you should define it as feild and you should include it in the constructor otherwise you will call uninitialized variable.
- You can use `@RequestMapping("/endpoint")` at the start of the class, then any Get/PostMapping will get prefix `/endpoint`
```java
@RequestMapping("/users")  
public class UserController {  
    private UserRepository userRepository;
	
	@GetMapping("/{id}")  // --> /users/id
	public User user(@PathVariable Long id){  
	    return userRepository.findById(id).orElse(null);  
	}
}
```
