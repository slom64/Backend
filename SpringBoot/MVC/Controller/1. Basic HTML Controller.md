- We should make the class as `@Controller` that make it bean, and managed by spring.
```java
@Controller  
public class HomeController {  
    @RequestMapping("/")  
    public String index() {  
        return "index.html";  
    }  
}
```
- We can send data from our Controller to a View, we can use `Model`. `Model` is a container for data which can be used to transfer data from Controller to view
```java
@RequestMapping("/")  
public String index(Model model) {  
    model.addAttribute("attribute 1","Value 1");  
    return "index.html";  
}
```
