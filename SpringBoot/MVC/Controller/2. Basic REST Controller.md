- Here we don't return name for html page, we return the actual data that will be sent to the user.
```java
@RestController  
public class MessageController {  
    @RequestMapping("/hello")  
    public String sayHello(){  
        return "Raw Hello World :D !";  
    }  
}
```
- Spring automatically convert java objects to json objects fromat
```java
@RestController  
public class MessageController {  
    @RequestMapping("/hello")  
    public Car sayHello(){  
        return new Car("Toyota");  
    }  
}

@AllArgsConstructor  
public class Car {  
    private String type;  
}
```

```json
//output
{
	"type":"Toyota"
}
```

Another example:
```java
@AllArgsConstructor  
public class UserController {  
    private UserRepository userRepository;  
  
    @RequestMapping("/users")  
    public List<User> getAllUsers(){  
        return (List<User>) userRepository.findAll();  
    }  
}
```
