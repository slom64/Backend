### Extracting query parameters
- `@RequestParam(name = "NameInRequest",required = false, defaultValue = "")`
```java
@GetMapping("/{id}")  
public ResponseEntity<User> getUser(
	@PathVariable Long id,
	@RequestParam(name = "sort",required = false, defaultValue = "") String sortBy,
	@RequestHeader(name = "x-auth-token", required = false) String authToken
	)
```

### Extracting Request Body
- `@RequestBody` which maps the body to specific class object.
```java
@PostMapping("/create-user")
public UserDto createUser(@RequestBody UserDto user){
	return user;
}
```
