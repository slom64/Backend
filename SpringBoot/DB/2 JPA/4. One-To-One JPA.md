- Same as One-To-Many you can decide who is the owner of the relationship based on the foreign key


```java
// Example User -- Profile
// Class that has the foreign key
@OneToOne
@JoinColumn(name = 'ForeignKeyInDatabase')
@MapsId  // This tells Hibernate to use the ID from the 'user' field as the primary key
public Class2 x;


// The other class
@OneToOne(mappedBy = 'x')
public Class1 y;
```

```java
@Entity(name = "profiles")
public class Profile {
    @Id
    private Long id; // Keep this as the numeric ID
	
    @OneToOne
    @MapsId // This tells Hibernate to use the ID from the 'user' field as the primary key
    @JoinColumn(name = "id")
    private User user; // This MUST be the User entity
	
}


// if you want to access profile from user
@OneToOne(mappedBy = "user", cascade = CascadeType.ALL)
private Profile profile;
```
