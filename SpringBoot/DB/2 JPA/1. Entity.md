- If you are not using hibernate for generating tables at runtime, you can skip putting `nullable = false` because its already defined in table schema when we created them before working with code.

```java
@Entity  
@Table(name = "users")  // map 'user' class to 'users' tables.
public class User {  
    @Id  // primary key
    @GeneratedValue(strategy = GenerationType.IDENTITY)  // Auto increment
    private Long id;  
  
    @Column(nullable = false, name = "name")  // map 'username' field to 'name' column in database 
    private String username;  
  
    @Column(nullable = false, name = "email")  
    private String email;  
  
    @Column(nullable = false, name = "password")  
    private String password;  
}
```
