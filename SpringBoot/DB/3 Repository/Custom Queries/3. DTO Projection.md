
> [!Summary]
> Use this to choose which columns you want to retrieve.
> The main idea is to have getters signatures that are same as the target entity getters.

Before projection, when we were quering an entity, we get the whole entity columns and its related entites even if we only need one column for our logic, this is inefficient. 
To solve this issue: 
1. we create an interface or class that has only the targeted columns that we want to retrieve. In most cases use interface, but if there is logic you want to add while doing queries then use class.
```java
// Interface
//com.store.dtos.ProductSummray
public interface ProductSummary {  
    Long getId();  
    String getName();
}
// or class
@Getter
@AllArgsConstructor
public class ProductSummaryClass{
	Long id;
	String name;
	
	Long getId();
	String getName();
}
```
2. Use the new interface or class as datatype for returend datatype from the query
```java
// with Derieved query
List<UserSummary> findById(int id);

// with Custom Query @Query and using the interface
@Query("Select u.id, u.name form user u where u.id = :id")
List<UserSummary> findUser(@Param("id")int id)

// with Custom Query @Query and using the class
@Query("Select new com.store.dtos.ProductSummrayClass(u.id, u.name) form user u where u.id = :id")
List<UserSummary> findUser(@Param("id")int id)
```
