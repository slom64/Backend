```java
@transactional
public void fetchUsers(){}
	var users = userRepository.findAll();
	users.forEach(User u ->{
		System.out.println(u);
		u.getAddresses().forEach(System.out::println);
	});
}
```
- This code will make hibernate fetch user by user, and for each user it will do another query to fetch each user address, it should make one query to fetch user by user and with this query it should have fetched the address too. This happens because `Lazy` loading, if you managed to make it `eager` loading it will load all the needed data in one query.
