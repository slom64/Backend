- Spring will automatically generate the implementaion for us.
- You can query using what ever field in the entity.

```java
public interface UserRepository extends JpaRepository<User, Long> {  
  
    //Queries based on "String"  
    List<User> findByName(String name);  
    List<User> findByNameLike(String name);  
    List<User> findByNameContaining(String name);  
    List<User> findByNameStartingWith(String name);  
    List<User> findByNameLikeIgnoreCase(String name);  
  
    //Queries based on "Numbers"  
    List<User> findByAge(int age);  
    List<User> findByAgeGreaterThanEqual(int age);  
    List<User> findByAgeBetween(int age1, int age2);  
  
    //Queries based on Null  
    List<User> findByNameNull();  
    List<User> findByNameNotNull();  
  
    //Multiple Conditions  
    List<User> findByNameLikeAndNameNull(String name);  
  
    //Sort (OrderBy)  
    List<User> findByNameOrderByAge(String name);  
  
    //limit (Top/First)  
    List<User> findTop5ByNameOrderByAge(String Name);  
}
```
