### Saving
```java
ConfigurableApplicationContext context = SpringApplication.run(DemoApplication.class, args);
var userRepository = context.getBean(UserRepository.class);
var user = User.builder().username("slom").password("slom123").email("slom.com").build();
userRepository.save(user); // Hibernate will auto generate sql statements for us.
```
- This basic insert will work because we deal with single object, but if we have 2 connected objects we want to insert them at once, it won't work. This is **Persisting related entity**. You have two solutions for this problem:
	- you save each object alone one by one
	- set the cascade type when defining entity and it relations `@OneToMany(cascade = CascadeType.PERSIST)`

### Delete
```java
userRepository.deleteById(1L);
```
- This will remove the entity but not its related entities
- To solve this issue use `@ManyToOne(cascade=CascadeType.REMOVE)`
	- But if there is no `ON DELETE CASCADE` in the database rules, this operation may fail because it may violate the integrity.
	- If you don't have the right to change the database schema you can enable cascade in application it self insted of relying on the database to do it. `cascade = {CascadeType.PERSIST, CascadeType.REMOVE}, orphanRemoval = true` 
		- `orphanRemoval` used to delete entities when they set to null, so we don't violate database integrity.
