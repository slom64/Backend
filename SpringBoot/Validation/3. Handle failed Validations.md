- In jakarta, When validation fails, It threw `MethodArgumentNotValidExecption` exception.
- Its better to implement global way to handle this execption so you don't need to repeat code for each time you use validation.

```java
@ControllerAdvice // This annotation allows us to handle exceptions globally across the whole application in one global handling component.  
public class GlobalExceptionHandler {  
  
    @ExceptionHandler(MethodArgumentNotValidException.class)  
    public ResponseEntity<Map<String,String>> handleMethodArgumentNotValidException( MethodArgumentNotValidException ex ) {  
        var errors = new HashMap<String, String>();  
        ex.getBindingResult().getFieldErrors().forEach((error) -> {  
            errors.put(error.getField(), error.getDefaultMessage());  
        });  
        return  ResponseEntity.status(HttpStatus.BAD_REQUEST).body(errors);  
    }  
}
```
