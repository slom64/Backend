### Don't use Jakarta validation for validating business rules
- If you want to validate business rules ("like there is unique email for each user registration"), **this should be done manually without using jakarta validation**, because those validations happens for each request which will cost database query. And if there were some validations have failed, the database query will happen despite of validation state. For best practice do manual checks after validating all user inputs, that will cost minimal database queries.

### Validations are applied on DTOs not on Entities
- Entites should focus persistence concerns, putting validtion on them creates coupling and validation duplication. So **put your validations on DTOs**.
