- Sometimes, we need more complex annotations than the built in ones.

---
## Steps
1. Create new Annotation
```java
package validation;

@Target(ElementType.FIELD)  
@Retention(RetentionPolicy.RUNTIME)
@Constraint(validatedBy = LowercaseValidator.class) //specifies the validation impelemntation class "We will create it next".
public @interface Lowercase {  
    String message() default "must be lowercase"; // This is just default value which can be changed.  
    Class<?>[] groups() default {};  
    Class<? extends Payload>[] payload() default {};  
}
```

2. Now implement the validation logic
```java
package validation;
//                                 < Name of the newly created annotation, DataType the the annotation will take>
public class LowercaseValidator  implements ConstraintValidator<Lowercase, String> {  
    @Override  
    public boolean isValid(String value, ConstraintValidatorContext context) {  
        if (value == null) {  
            return true; // Null values are considered valid. Use @NotNull to enforce non-null.  
        }  
        return value.equals(value.toLowerCase());  
    }  
}
```
