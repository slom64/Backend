- Beans have life cycle, they get initialized then it's dependecies get injected then when they are no longer needed they get destroyed.
- We can hook to different stages to perform specific actions like initialize those resources or clean them up.


| Annotation       | Description                                                                                  |
| ---------------- | -------------------------------------------------------------------------------------------- |
| `@PostConstruct` | This mehod is called after the bean get **created** and `initialized` "`Calling construtor`" |
| `@PreDestory`    | Execute code just before the object getting destoryed                                        |
