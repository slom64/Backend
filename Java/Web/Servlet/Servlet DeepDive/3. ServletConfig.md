- The ServletConfig interface is used by a servlet to obtain some of the configuration written specfically for it in the deployment descriptor file (`web.xml`). So if there is specific configurations we need to pass it to our servlet we will use `web.xml` and `ServletConfig`.
- Such Configuration information is better written in the xml file instead of hard coding it inside  the serlvet's code. Such approach makes it easy to alter such inforamtion after the servlet's source code has been compiled.
- Each servlet is passed its own set of configuration parameters.
- **It is passed by the servlet container to the `init()` method as parameter**. `public void init(ServletConfig servletConfig) throws ServletException`

---
### Define parameters
We can send the parameters from `web.xml` as following:
```xml
<servlet-name>myservlet</servlet-name>  
<servlet-class>com.servlet.MyServlet</servlet-class>
<init-param>
	<param-name>Admin Email</param-name>
	<param-value>admin@gmail.com</param-value>
</init-param>
<init-param>
	<param-name>Admin password</param-name>
	<param-value>Password1!</param-value>
</init-param>
```

---
### Use parameters
- Methods in `ServletConfig` interface
	- `getInitParameterNames()`: Enumerate all parameters names
	- `String getInitParameter(String paramName)`: get specific parameter value based on its name
	- `String getServletName()`: get the servlet name inside the configuration file web.xml
	- `ServletContext getServletContext()`:
```java
public class MyServlet implements Servlet {  
    ServletConfig config;  
    @Override  
    public void init(ServletConfig servletConfig) throws ServletException {  
        config = servletConfig;  
    }
    public void service(ServletRequest servletRequest, ServletResponse servletResponse) throws ServletException, IOException {  
    String email = config.getInitParameter("Admin Email");  
    PrintWriter out = servletResponse.getWriter();  
    out.println("<h1>Email is: " + email +"</h1>" );  
    System.out.println("<h1>Welcome to Web Dev.</h1>");  
}
```
