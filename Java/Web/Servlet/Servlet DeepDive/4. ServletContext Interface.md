- It define global informations that is useful for the whole application Ex. **DollarExchangeRate = 5.6**
- Provides information to servlets about the environment in which they are running.
- It represents a context within which a web application executes.
- Each web application has only one `ServletContext` object.
- Defines a set of methods that a servlet uses to communicate with its servlet
- You can access the servlet context of servlet through the `ServletConfig`, using the method `getServletContext()`
- The ServletContext object gives you the ability to:
	- bind an object attribute into the context by name. which will be available to any other servlet that is part of the same web application.
	- Read Context initialization parameter from the `<context-param>` tag written in the `web.xml`.
- Methods inside this interface
	- `Enumeration getInitParameterNames()`
	- `String getInitparameter(String paramName)`
	- `Enumeration getAttributeNames()`
	- `Object getAttribute(String attName)`
	- `void setAttribute(String attName, Object value)`: you can set parameter in runtime.
	- `void removeAttribute(String attName)`

> [!NOTE] Attribute vs parameter
> Parameter is information coming externally which is most of the time from `web.xml`. Attribute is information have been set in runtime, and we deal with as object.


---
### How to define it?
- The whole `<context-param>` tag is repeated for each parameter. It should be placed at the beginning of the file.
- Context Parameters of a web application (context params) can be written inside the `web.xml` file as follows:
```xml
<web-app>
	<context-param> <!-- notice: the parameter isn't under any servlet because it define general, global information in the whole application. -->
		<param-name>DollarExchangeRate</param-name>
		<param-value>5.6</param-value>
	</context-param>
</web-app>
```

---
### How to use it?
```java
public class MyContextSetter implements Servlet
{
	ServletConfig conf;
	public void init(ServletConfig config) throws ServletException
	{
		conf = config;
	}
	
	public void service(ServletRequest request, ServletResponse response) throws ServletException, IOException
	{
		ServletContext servletContext = conf.getServletContext();
		PrintWriter out = response.getWriter();
		String str = servletContext.getInitParameter("AdminEmail");
		out.println("Admin email is: "+ str);
		servletContext.setAttribute("MyPassword","iti"); // setting attribute.
		
		String str = (String)servletContext.getAttribute("MyPassword");
		out.println("My Password is: " + str);
	}
}
```

## ServletConfig vs ServletContext

| ServletConfig                                                                                                      | ServletContext                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| Both are for setting configureation                                                                                | Both are for setting configureation                                                                                         |
| It is an interface provided by the Servlet API.                                                                    | It is an interface provided by the Servlet API.                                                                             |
| Represents the configuration of a `specific servlet`                                                               | Represents config of the `entire web application`                                                                           |
| `Each servlet has its own ServletConfig object`, which is created by the servlet conatiner `during initialization` | There is` only one ServletContext` object per web application created by the servlet container `during application startup` |
| Only the target servlet can access this parameter                                                                  | Any servlet can access this parameter                                                                                       |
