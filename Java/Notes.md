- When define method as `static` that mean we don't need to create an object from the class to call this method. So we can call the method using the class name only.
  `Static` can only handle `static` attributes.
- When we compile `.java` file, we will get `.class` file.
- When you put `public class vehicle` that mean other classes can create objects from this class.
- Instance members attributes that has dedicated value for each object, static members: attributes that are shared across all objects in a class.
- When we call method of class from an object, java sends implicitly a hidden paramter that refere to object address in memory when we call any object method which is `this`.
